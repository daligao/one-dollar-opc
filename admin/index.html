$1 OPC — Admin Console

Updates company state via Cloudflare KV. Must be behind Cloudflare Access.

⚠️ This console must be protected by Cloudflare Access. Without it, anyone can overwrite company state via /api/admin/state. Do not share or expose this URL.

How to use this console

  1. Click Load Current State to pull existing data from KV (or fallback JSON)
  2. Edit company numbers, mission, or milestone statuses
  3. Add OPC Log entries for major milestones — newest entry goes first
  4. Click Save to KV to publish
  5. Open the public homepage in a new tab and refresh to verify

If KV is unavailable, data falls back to /data/company.json (read-only). Saving requires the OPC_STATE KV binding to be active.
